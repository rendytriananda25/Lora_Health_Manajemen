LAMPIRAN: DAFTAR PUSTAKA LIBRARY (DEPEDENSI) APLIKASI

Dalam pengembangan aplikasi Lora Health Management, penulis memanfaatkan berbagai pustaka (library) eksternal untuk memastikan kinerja aplikasi yang optimal, aman, dan berskala industri. Berikut adalah daftar library yang digunakan beserta fungsinya masing-masing:

1. Manajemen State & Arsitektur Inti

  • provider: Digunakan sebagai pengelola state (State Management) utama aplikasi, mendukung penerapan Clean Architecture agar logika bisnis dan antarmuka (UI) terpisah dengan baik.

2. Backend, Database & Autentikasi (Firebase)

  • firebase_core: Penghubung inti antara aplikasi Flutter dengan infrastruktur cloud Firebase.
  • firebase_auth: Menangani sistem autentikasi dan keamanan akses pengguna secara real-time.
  • firebase_database: Mengelola Realtime Database untuk sinkronisasi riwayat olahraga, kalori, dan metrik kesehatan pengguna antar perangkat.
  • cloud_firestore: Database tambahan untuk menyimpan struktur dokumen hierarkis yang lebih kompleks.
  • google_sign_in: Mengaktifkan integrasi otorisasi pihak ketiga (Single Sign-On) menggunakan akun Google.
  • flutter_facebook_auth: Mengaktifkan integrasi otorisasi pihak ketiga menggunakan akun Facebook.

3. Sistem Pemetaan, GPS & Tracking Olahraga

  • geolocator & geolocator_android: Mesin utama untuk mengakses dan memantau sensor GPS perangkat (Location Services). Berfungsi mengukur kecepatan dan jarak tempuh olahraga.
  • flutter_map: Menyediakan kanvas peta interaktif berbasis data OpenStreetMap untuk memvisualisasikan rute pengguna.
  • latlong2: Library matematis untuk kalkulasi jarak dan interpolasi koordinat Latitude/Longitude dengan tingkat presisi tinggi.

4. Proses Latar Belakang & Sistem Notifikasi

  • flutter_local_notifications: Mengelola dan memunculkan notifikasi antarmuka di perangkat pengguna (contoh: Notifikasi rekaman aktif).
  • flutter_background: Memastikan proses pelacakan (tracking) GPS tidak dimatikan paksa oleh sistem operasi Android saat layar perangkat dimatikan.
  • alarm & timezone: Menangani penjadwalan alarm atau pengingat sesi olahraga secara lokal, yang disesuaikan dengan zona waktu pengguna.

5. Antarmuka Visual & Pengolahan Media

  • youtube_player_flutter: Menanamkan (embed) pemutar video tutorial dari YouTube langsung ke dalam aplikasi.
  • audioplayers: Menangani pemutaran efek suara (Sound Effects) antarmuka dan notifikasi peringatan olahraga.
  • smooth_page_indicator: Membuat indikator navigasi halaman yang mulus pada menu panduan olahraga.
  • mobile_scanner: Memanfaatkan sensor kamera untuk keperluan pemindaian QR Code dan Barcode.

6. Utilitas, Pemformatan & Penyimpanan Lokal

  • shared_preferences: Mengelola penyimpanan data preferensi lokal yang bersifat ringan, seperti pengaturan tema (Dark/Light Mode) dan preferensi bahasa.
  • http: Memfasilitasi permintaan jaringan ke API eksternal, khususnya untuk menarik data cuaca dari OpenWeatherMap.
  • intl: Menangani pemformatan lokalisasi teks, angka, dan konversi format penanggalan yang kompleks.
  • permission_handler: Menangani alur perizinan akses komponen perangkat keras (Lokasi, Kamera, Notifikasi) secara elegan sesuai standar keamanan sistem operasi.
  • url_launcher: Membuka tautan eksternal (browser, telepon, atau surel) langsung dari dalam aplikasi.
  • country_code_picker: Memfasilitasi antarmuka pemilihan kode negara untuk keperluan profil pengguna.
  • file_picker & path_provider: Mengakses sistem penyimpanan internal (Storage) perangkat untuk memilih file atau gambar dari galeri pengguna.
Argumen Pertahanan (Defense Argument) untuk Sidang:
Jika ditanya mengenai banyaknya pustaka yang digunakan, Anda dapat menjawab: "Aplikasi ini dibangun bukan sekadar sebagai purwarupa (prototype), melainkan ditargetkan sebagai aplikasi produksi (Production-Ready). Sebagai contoh, kombinasi flutter_background dan geolocator_android merupakan best practice wajib di industri agar pelacakan GPS dapat berjalan stabil di latar belakang, tanpa terinterupsi oleh fitur penghemat baterai sistem operasi Android."
